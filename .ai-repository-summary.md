## Purpose

Scrape competitor app reviews (1–3 stars) from digital marketplaces, cluster and
analyze negative reviews with LLMs, and surface ranked, monetizable **feature
gaps** via a Blazor dashboard for human strategic review. **Not** a
customer-facing product.

## Tech Stack

- **Runtime:** .NET SDK 8.0.x (LTS); `global.json` → `8.0.100`, `rollForward: latestFeature`
- **Orchestration:** .NET Aspire 8.2.x
- **UI:** Blazor Web App (Interactive Server)
- **API:** ASP.NET Core Minimal API
- **DB:** PostgreSQL 16 + pgvector 0.7; EF Core 8.0.x
- **Cache/Queue:** Redis 7 (StackExchange.Redis); Hangfire 1.8.x
- **AI:** Microsoft.SemanticKernel 1.20.x; Azure OpenAI / Anthropic
- **Scraping:** Apify API v2 (Refit 7.x)
- **Validation:** FluentValidation 11.x
- **Testing:** xUnit 2.9 + NSubstitute 5.1 + Testcontainers 3.10

## Build & Test

```bash
dotnet restore GapMiner.sln
dotnet build   GapMiner.sln --configuration Release
dotnet test    GapMiner.sln --configuration Release
```

CI: `.github/workflows/ci.yml` (all actions SHA-pinned; .NET 8.0.x via setup-dotnet).

Local dev: `dotnet run --project src/GapMiner.AppHost` (Aspire provisions Postgres + Redis + services).
Standalone: `docker compose up --build`.
