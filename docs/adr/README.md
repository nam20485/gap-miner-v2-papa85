## When to write an ADR

Per the development plan escalation protocol (§18), write an ADR whenever you
encounter an ambiguity **not** covered by the plan, or before making a
security-sensitive or hard-to-reverse architectural choice. Never guess on
Apify actor IDs, LLM provider endpoints, or security design — document the
decision point and request human clarification.
